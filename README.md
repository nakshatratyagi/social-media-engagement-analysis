# Social Media Engagement Analysis

## Project Overview
This project analyzes social media engagement data to identify patterns, trends, and factors associated with successful social media posts.

The analysis explores how different platforms, content types, topics, hashtags, posting days, sentiment, and audience regions relate to engagement and viral performance.

## Dataset Information
- Total Records: 2,000
- Total Features: 15
- Time Period: January 2024 – December 2024
- Platforms: Instagram, TikTok, X, YouTube Shorts

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Data Loading and Exploration
2. Data Cleaning and Validation
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Platform Performance Analysis
6. Content Type and Topic Analysis
7. Hashtag Analysis
8. Sentiment Analysis
9. Viral Content Analysis
10. Correlation Analysis
11. Data Visualization
12. Business Insights and Recommendations

## Key Findings

- X recorded the highest average engagement rate at 20.10%.
- Text-based content achieved the highest average engagement rate at 18.39%.
- Monday recorded the highest weekday engagement at 21.60%.
- June recorded the highest monthly average engagement at 34.37%.
- Lifestyle was the highest-performing topic at 20.46%.
- #funny recorded the highest hashtag engagement at 18.07%.
- The UK recorded the highest regional engagement at 19.59%.
- Positive sentiment showed slightly higher average engagement than negative sentiment.

## Business Recommendations

- Experiment with text-based content to improve engagement.
- Evaluate platform-specific content strategies.
- Investigate high-performing topics and hashtags.
- Analyze audience preferences across different regions.
- Monitor unusual engagement values before making business decisions.
- Conduct further experiments to validate the observed patterns.

## Limitations

- Posting-hour analysis was limited because all timestamps were recorded at midnight.
- Extreme engagement values influenced monthly averages.
- Correlation analysis identifies associations, not causation.
- Findings are based on the available 2024 dataset.

## Conclusion

The project demonstrates how exploratory data analysis can uncover useful social media engagement patterns. By analyzing platform performance, content formats, topics, hashtags, sentiment, and viral status, businesses can develop more informed content strategies.

The findings provide a starting point for data-driven social media optimization and further analysis.
